Comment demander de l’aide

Envoyez un email à sciencezvousyt@gmail.com depuis l’adresse que vous consultez régulièrement. Indiquez le sujet de votre demande, la version d’Android si vous la connaissez, et une description courte du comportement observé.

Signaler un bug

Dans votre message, précisez les étapes pour reproduire le problème, le message d’erreur éventuel et si le souci apparaît après une mise à jour récente. Une capture d’écran peut aider lorsqu’elle ne contient pas d’informations sensibles.

Demander la suppression de données

Consultez la page dédiée Suppression des données pour le détail des informations utiles à inclure dans votre email.

Délais de réponse

Les messages sont traités dans des délais raisonnables, en fonction du volume de demandes. Aucun délai de réponse fixe ni aucun engagement de niveau de service (SLA) n’est garanti par ce support email.
