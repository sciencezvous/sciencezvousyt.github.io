3. Description du service

Vokly est une application Android centrée sur la messagerie Vokly-to-Vokly, Agent Vokly et une inbox externe optionnelle lorsque l'utilisateur accorde les autorisations nécessaires.

  • Messagerie Vokly-to-Vokly : conversations, contacts Vokly, profils, avatars, statuts de message et notifications.
  • Agent Vokly : aide à la rédaction, reformulation, suggestion, résumé ou génération de sujet d'email selon le plan ou le quota disponible.
  • Inbox externe optionnelle : affichage ou actions contextuelles sur certaines notifications Android, uniquement si l'utilisateur active les autorisations correspondantes.

L'utilisateur garde le contrôle et valide les contenus avant envoi. L'envoi automatique n'est pas actif dans cette version.

4. Agent Vokly, quotas et plans

Les fonctions IA d'Agent Vokly peuvent être limitées selon le plan Free, Plus ou Premium. La génération de sujet d'email via /subject est conservée et peut être comptabilisée selon le quota ou le plan disponible.

Mistral est le fournisseur IA principal. OpenAI peut être utilisé comme fournisseur de secours lorsque nécessaire. Les résultats générés peuvent être inexacts ou inadaptés : l'utilisateur doit les vérifier avant toute utilisation.

5. Achats et abonnements

Si des achats intégrés ou abonnements sont proposés, ils sont gérés par Google Play Billing. Les annulations, renouvellements, remboursements et données de facturation suivent les règles de Google Play.

6. Sécurité et limites

Vokly utilise des services sécurisés comme Firebase/Google et Cloudflare pour certaines fonctions. Cependant, Vokly n'est pas une messagerie chiffrée de bout en bout dans cette version.

Les publicités récompensées ne sont pas actives dans cette version. Elles pourront faire l'objet d'une mise à jour des pages légales si elles sont ajoutées plus tard.
